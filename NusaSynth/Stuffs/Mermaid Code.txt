flowchart TB
SEED["<span style='font-size:26px !important'><b>Seed Data</b></span>
───────────────────
• NusaX-Senti
• 500 data latih per bahasa
• Seed Profile per label"]

CA["<span style='font-size:30px !important'><b>Contextualizer Agent</b></span>
──────────────────────────────────────────
<b>Input:</b>
    • 5 kalimat seed per batch
<b>Process:</b>
    • Analisis domain, gaya, dan ekspresi sentimen per seed
<b>Output:</b>
    • Rencana variasi per seed (strategy + preserve)"]

DG["<span style='font-size:30px !important'><b>Generator Agent</b></span>
───────────────────────────────────
<b>Input:</b>
    • Rencana variasi
    • Referensi seed
    • Seed profile (mean & std panjang kalimat)
<b>Output:</b>
    • Kalimat sintetis dalam bahasa daerah target
<b>Constraint:</b>
    • Sentimen sesuai label target
    • Panjang mengikuti seed profile
    • Tidak menjiplak seed
    • Tiap kalimat berbeda secara struktural"]

SV["<span style='font-size:30px !important'><b>Sentiment Validator (SV) Agent</b></span>
────────────────────────────────────────
<b>Input:</b>
    • Kalimat sintetis
    • Prediksi NusaBERT (label + confidence)
    • Seed sebagai konteks
<b>Process:</b>
    • Chain-of-Thought reasoning untuk validasi sentimen
    • Prediksi NusaBERT sebagai acuan pendukung
<b>Output:</b>
    • PASS / REJECT
    • Umpan balik diagnostik"]

LV["<span style='font-size:30px !important'><b>Linguistic Validator (LV) Agent</b></span>
──────────────────────────────────────────
<b>Input:</b>
    • Kalimat sintetis
    • Identifikasi GlotLID (bahasa + confidence)
    • Seed sebagai konteks
<b>Process:</b>
    • Chain-of-Thought reasoning untuk penilaian kealamian
    • Deteksi language confusion
    • Identifikasi GlotLID sebagai acuan pendukung
<b>Output:</b>
    • PASS / REJECT
    • Umpan balik diagnostik"]

PSLM["<span style='font-size:30px !important'><b>Per-Sentence Length Match (PSLM)</b></span>
───────────────────────────────────────────
<b>Input:</b>
    • Kalimat lolos LV
    • Seed profile (mean & std panjang kalimat)
<b>Process:</b>
    • Bandingkan panjang kalimat vs rata-rata seed per label
<b>Constraint:</b>
    • Deviasi ≤ 1.0 × std per label
<b>Output:</b>
    • Lolos / kembali ke Generator"]

DEDUP["<span style='font-size:30px !important'><b>Cross-batch Deduplication</b></span>
─────────────────────────────────────────
<b>Input:</b>
    • Kalimat lolos PSLM
<b>Process:</b>
    • Hitung Jaccard bigram similarity vs korpus sintetis sebelumnya
<b>Constraint:</b>
    • Similarity < 0.5
<b>Output:</b>
    • Disimpan / difilter sebagai duplikat"]

OUT["<span style='font-size:30px !important'><b>Synthetic Dataset</b></span>
───────────────────────
Korpus data sintetis tervalidasi"]

SEED --> CA
CA --> DG
DG --> SV
SV -- Lolos --> LV
SV -- "Tolak + umpan balik" --> DG
LV -- Lolos --> PSLM
LV -- "Tolak + umpan balik" --> DG
PSLM -- Lolos --> DEDUP
PSLM -- "Tolak + umpan balik" --> DG
DEDUP --> OUT
